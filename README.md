# VargaMesh AuxPoW Bridge

Reference tooling for integrating VargaMesh (VMESH) as an AuxPoW child chain
of Bitcoin.

Included:
- VMESH child-template generation
- AuxPoW metadata validation
- candidate validation
- AuxPoW proof construction
- VMESH `submitblock` submission

Companion CKPool integration:
https://github.com/ati1993de/vargamesh-ckpool-auxpow
